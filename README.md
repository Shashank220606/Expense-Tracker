# 💰 Expense Tracker – Budget Like a Pro!

Welcome to **Expense Tracker**, a smart and intuitive web application designed to help users manage their finances with an intuitive dashboard and budgeting tools.

## 🌐 Live Demo

[Open Expense Tracker](https://shashank220606.github.io/Expense-Tracker/expense_tracker/index1.html)

*Note: The application is a frontend demo with sample data. For production use, backend integration is needed.*

---

## ✅ Current Features

- 📊 **Dashboard** – Display income, expenditure, and savings overview
- 🎨 **Light/Dark Theme Toggle** – Switch between light and dark modes with persistent preference
- 📱 **Responsive Dashboard Layout** – Clean and modern UI with Material Design
- 📋 **Sample Transaction History** – View transaction details and status
- 📈 **External TradingView Links** – Quick access to Bitcoin, XRP, and Ethereum charts
- 🔗 **External Chatbot Link** – Connect to AI chatbot for budgeting assistance
- 🎭 **Login Page Design** – User-friendly authentication interface

---

## ⚠️ Current Limitations

- The displayed financial values are **sample data** and do not reflect actual user transactions
- **No backend or database** is currently connected
- Login functionality is currently a **frontend interface only** (no authentication)
- Notifications and transaction history actions show "coming soon"
- Cryptocurrency information is provided through **external TradingView links**
- The chatbot is hosted **externally** and not integrated into the app
- User data is not persisted between sessions
- Limited mobile responsiveness

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Icons:** Google Material Symbols
- **Charts:** TradingView (external links)
- **Storage:** Browser localStorage (theme preference only)
- **Chatbot:** External integration

## 🚀 Getting Started

### Run Locally

1. **Clone the repository:**

   ```bash
   git clone https://github.com/Shashank220606/Expense-Tracker.git
   cd Expense-Tracker
   ```

2. **Open the project folder:**

   ```bash
   cd expense_tracker
   ```

3. **Open `index1.html` in your browser:**

   - Double-click `index1.html` to open it directly, or
   - Use a local server (recommended):

   ```bash
   python -m http.server 8000
   ```

   Then visit: `http://localhost:8000`

4. **Login with sample credentials:**

   - The login page is a frontend demo
   - Enter any username and password to proceed to the dashboard

## 🎯 How to Use

1. **Start the Application:** Open `index1.html` in a web browser
2. **Login:** Enter any username and password (no validation required)
3. **Explore Dashboard:** View the sample income, expenditure, and savings data
4. **Toggle Theme:** Use the light/dark mode button in the top-right corner
5. **View Transactions:** Check the transaction history table with sample data
6. **Access Chatbot:** Click "Chat Bot" in the sidebar to open the external chatbot
7. **Check Stocks:** Click on Bitcoin, XRP, or Ethereum cards to view live charts on TradingView
8. **Logout:** Click the logout button to return to the login page

## 📖 Next Steps for Production

To make this a fully functional application, you will need to:

1. **Set up a backend server** (Node.js, Python Flask, etc.)
2. **Implement a database** (MongoDB, PostgreSQL, SQLite, etc.)
3. **Add user authentication** (JWT, OAuth, session-based)
4. **Create API endpoints** for expense management
5. **Integrate real expense tracking** functionality
6. **Add chart libraries** (Chart.js, D3.js, or similar) for dynamic visualizations
7. **Implement notifications** using push notifications or email
8. **Deploy to production** (Netlify, Vercel, Heroku, or cloud provider)
